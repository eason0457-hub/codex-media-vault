# codex-media-vault

A lightweight public media vault for Codex projects.

## Structure

- `video/` — source videos and visual references
- `audio/` — music, extracted audio, voice, and sound assets
- `frames/` — keyframes or screenshots extracted from video
- `images/` — still-image references and artwork
- `projects/` — project-specific grouped assets

## Instructions for Codex

When a task mentions this vault:

1. Read the repository structure first.
2. Reuse existing assets instead of asking for the same file to be uploaded again.
3. Do not overwrite or delete source media unless explicitly requested.
4. For video work, prefer using the original source file when available; use `frames/` and `audio/` for lightweight analysis when appropriate.
5. If multiple similarly named assets exist, inspect filenames and metadata before choosing one.
